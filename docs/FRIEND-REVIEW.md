# Friend review brief

Ask a peer to install Brain from source or `.pkg` and spend ~20 minutes.

## Goals

1. Can they set a vault path without help?
2. Does search + graph feel useful in under 5 minutes?
3. Do they understand *why* TL;DR cards beat dumping folders into chat?

## Ask them to note

- First friction point
- Whether they trust locking `secure/` cards
- Whether agent install (`brain agents install`) is clear

Use `BUGREPORT-TEMPLATE.md` for defects. No secrets in shared notes.
