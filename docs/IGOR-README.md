# Tester handoff (Igor / friends)

English brief for someone installing Brain for the first time.

## Install

1. Install the `.pkg` from a release or build via `docs/BUILD.md`.
2. Open **Brain.app** (or `brain desktop`).
3. Settings → set vault path (absolute folder, often Google Drive).
4. Set master password once if you will use `secure/` cards.

## Smoke checklist

- [ ] Graph loads cards
- [ ] Search finds a known slug
- [ ] Unlock / lock works
- [ ] Close window → menu-bar brain icon remains
- [ ] Open Brain.app again → window shows
- [ ] Dashboard → Remember + Add card
- [ ] `brain doctor` reports `ok` / useful warnings only

## Feedback

Use `docs/BUGREPORT-TEMPLATE.md` or the in-app feedback form. No passwords or PEM contents in reports.
